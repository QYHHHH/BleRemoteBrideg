03 / BUILT TO BE SIMPLE

少装一点，多用一点。

桥接在开发板上完成，电脑端用标准蓝牙键盘连接。需要改设置时，再打开网页。

小成本改造

开发板约 10 元，加一只兼容蓝牙遥控器。优先利用已经有的设备。

标准键盘连接

向电脑输出蓝牙键盘与媒体控制报告，不依赖额外的键盘映射客户端。

浏览器里完成配置

连接、配网、按键设置各有入口。已有固件的设备，不必为了改 Wi-Fi 再烧一遍。

快捷键，按你的习惯

单键、修饰键组合、媒体控制。选择你用得上的，不增加不需要的复杂度。

按键在本地转发

遥控器与电脑的按键链路走蓝牙；设备配置页的 Wi-Fi 开放有独立时间窗口。

开源，可继续改造

固件以 GPL-3.0-or-later 发布。保留清晰的源码和配置，方便继续研究与改进。

ESP Web Tools · 官方组件

第一次拿到裸板，也只需要点一次“连接设备”。

选择串口后，ESP Web Tools 会先尝试识别设备上的 Improv Serial。已是 MiRemoteBridge 就直接给出管理功能；识别不到或不是本项目固件，就显示安装入口。安装完成后继续用同一个官方窗口配置 Wi-Fi、打开设备页或查看日志。

当前浏览器不支持 Web Serial，请使用支持 Web Serial 的桌面浏览器。 设备连接需要 HTTPS 或 localhost。

串口选择时点“取消”也不用自己处理。 官方组件会显示“No port selected”，继续提供数据线检查、常见 USB 转串口驱动链接和 Try Again。

为什么现在不再单独做“连接 USB / 配 Wi-Fi / 打开配置页”三套逻辑？
因为 ESP Web Tools 本身已经把这些状态串在一个连接会话里：先尝试 Improv 识别，再根据固件状态显示安装或更新；支持 Improv 时继续提供 Connect / Change Wi-Fi、Visit Device；同时保留 Logs & Console。网站只负责提供 MiRemoteBridge 的 manifest 和统一入口，不再复制官方已经实现的串口状态机。
“仅升级 APP”为什么放在高级选项？
APP-only 只能安全用于已经有正确 bootloader / 分区表的 MiRemoteBridge 设备。它的优势是不会主动写 NVS，因此能保留键位和配对；但如果分区布局已经变化，或者拿裸板直接刷 app.bin，设备可能无法启动。部署时必须让 MRB_CONFIG.appManifest 指向由当前构建生成、偏移经过确认的 APP-only manifest。
