ESP32-C3 · 开源固件 · GPL-3.0

让电脑把遥控器当成普通键盘

MiRemoteBridge 是一份跑在 ESP32-C3 上的固件。它一边连蓝牙遥控器，一边以 标准蓝牙键盘的身份连电脑——免驱、不装软件、不改系统、 不影响游戏反作弊、不需要管理员权限。

开始使用 查看源码

整套成本约 15–25 元：开发板 ≈ 10 元 + 遥控器 ≈ 5 元起。

使用场景

遥控器到手能干啥

电脑接收的所有按键都是标准 HID 报告，所以遥控器能干的事和普通键盘一模一样。

看视频

方向键跳进度，音量键调音量，TV 键全屏。沙发上看电影，遥控器在手里就能搞定一切。

Vibe Coding · 语音写代码

按住语音键对 AI 说需求，松开自动转写。方向键移光标，确认键提交，双手不离开键盘位置。

媒体与演示

听歌暂停/切歌、看图全屏、PPT 翻页——所有媒体键都能用，躺在床上也能控制播放。

工作原理

一个板子，两头都是蓝牙

板子以 Central 身份连接遥控器，把它的按键码翻译（或透传）成标准 HID 报告， 再以 Peripheral 身份发给电脑。电脑看到的只是一个普通的蓝牙键盘， 所有翻译都发生在板子上。

真实配置界面

在浏览器里改键、看状态、换遥控器

无需装客户端、无需串口命令。所有用户操作都在网页里完成。

01 · 按键映射

13 键全映射，点哪个改哪个

RC003 的电源、方向、确认、菜单、TV、语音、音量键全部可改。每个键配一张可编辑卡片，改完自动保存。

  • 基础 / 编辑 双状态，未保存前蓝色高亮
  • 支持单键、组合键（Ctrl+Win、Win+Tab）
  • 改键无需重启，按下遥控器电脑立刻响应

02 · 多遥控器切换

3 个独立槽位，换遥控器不用重配

板子支持 3 个槽位：小米的 RC003 预设 + 2 个学习型。切换槽位瞬间完成，不打断当前连接。

  • 槽位状态：已连接 / 未启用 / 未添加设备
  • 每个槽位独立保存按键映射与设置
  • 显示电量、设备标识、MAC 地址

03 · 系统状态

引脚含义、堆内存、连接状态一目了然

开发板上每个 LED 的呼吸 / 快闪 / 常亮分别代表什么、堆内存水位到多少、历史最低还剩多少——全部实时可见。

  • D5 / D4 / RST / BOOT 四个关键引脚的语义
  • 堆内存环形图：当前、历史最低、最大连续块
  • 两个连接状态指示：网页控制 + 被控蓝牙

为什么是它

绕开所有麻烦的那条路

市面上给电脑配遥控器的方案，几乎都要在电脑上装点什么：驱动、后台服务、 虚拟设备、自启动项。这些正是游戏反作弊和杀毒软件最警惕的东西。

成本

一杯奶茶的钱

ESP32-C3 开发板约 10 元，最便宜的机顶盒蓝牙遥控器 5 元起，整套 15–25 元。

免装软件

浏览器打开就能烧

烧录用 Web Serial，配置用网页。电脑上永远不需要留一个客户端。

不改系统

不碰驱动和注册表

不动 Windows 驱动、不动注册表、不动组策略，卸载就是把 USB 拔了。

反作弊

纯 HID，不放任

输出标准 HID 报告，Riot Vanguard / EAC / BattlEye 等主流反作弊放行。

杀毒软件

没有任何可疑行为

不开后台、不写自启动、不联网（除非你主动打开配置页），零遥测。

权限

不需要管理员

配对走系统蓝牙设置；烧录走 USB 串口，普通用户权限即可。

兼容性

哪些能用，哪些不能

角色设备状态
遥控器小米蓝牙遥控器 2 Pro（RC003）实测可用
遥控器中国移动语音遥控器（CMCC_Voice_Remote）实测可用（部分物理键无响应）
遥控器其它标准 BLE 遥控器学习型槽位，标准键名自动识别，无需改代码
电脑Windows 10 / 11实测可用
电脑Linux / macOS未验证（标准蓝牙 HID，理论可用）
电脑iPhone / iPad（iOS）不支持

开始使用

连接设备

接上 USB，选固件，点一下。剩下的（配 Wi-Fi、进配置页、改键）页面会带着你走完， 全程不需要串口命令。

  1. 用 USB 线把 ESP32-C3 开发板接到电脑（数据线，不是纯充电线）
  2. 在下面选一个固件来源：官方最新固件，或你自己电脑上的文件
  3. 点「连接设备」，浏览器弹窗里选串口（CH343 / USB Serial / COMx）
  4. 烧完页面会让你填家里的 Wi-Fi；配网成功后自动跳转到板子的配置界面
点击选择固件文件，或把它拖到这里
已找到设备： — 若浏览器没有自动跳转，点这里进入配置界面。

⚠ 必须用 *.merged.bin（约 4 MB，含 bootloader + 分区表 + app）。 单独那个 1.3 MB 的 app 固件烧进去起不来——bootloader 不在里面。

⚠ 浏览器要求：桌面版 Chrome / Edge / Opera。Web Serial 只有它们支持， Firefox、Safari、国产浏览器（QQ / 百度 / UC / 360）以及手机都不行。 页面还必须在 HTTPS 或 localhost 下打开，file:// 会被 CORS 挡掉。

· 串口命令（status / scan / connect 等） 只用于调试，日常使用全部在网页里完成。
